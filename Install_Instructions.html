G-REDscript Profiler

v1.0.0 — Installation, synchronized capture, collection and restore guide

KEYBIND → SETUP → INSTALL → CAPTURE → COLLECT → RESTORE

RED4ext — required

G-REDscript Profiler is a native RED4ext plugin. Cyberpunk 2077 and a working RED4ext installation are required before the profiler can be installed.

Frame-time profiler — recommended

G-REDscript Profiler works standalone, but pairing the REDscript capture with frame-time data lets the report compare script activity with actual rendered-frame behavior. This build was designed and tested alongside CapFrameX 1.9.1.2 Beta.

CapFrameX releases on GitHub
Capture key: G-REDscript Profiler uses F11 for START and STOP + EXPORT. If you pair it with a frame-time tool, configure that tool to use the same key so both captures start and stop together.
0

MATCH THE FRAME-TIME CAPTURE KEY

G-REDscript Profiler itself uses F11. There is no separate REDscript keybind page to configure. Only the optional frame-time tool needs to be matched to F11.

  1. Open CapFrameX and go to the CAPTURE tab.
  2. Under Capture settings, set Capture hotkey to F11.
  3. Leave capture time at 0 if you want F11 to control START and STOP manually.
  4. If you use another frame-time tool, configure its capture key to F11 instead.
1

SETUP

  1. Extract the release ZIP to a normal writable folder and run G-REDscript-Profiler.exe from the profiler folder.
  2. Select the Cyberpunk 2077 game root. The profiler checks that the game and RED4ext are present.
  3. G-REDscript Profiler works standalone. If you want frame-time correlation, keep Run with a frame-time capture tool enabled.
  4. Select the frame-time profiler executable and its capture/results folder.
  5. Confirm the displayed key information shows G-REDscript Profiler on F11 and, when linked, the frame-time tool on the same key.
  6. Click CONTINUE →.
2

INSTALL THE PROFILER

  1. The status page should show the game and RED4ext as installed and report that the REDscript profiler is ready to deploy.
  2. Enter a useful Capture title, for example WORLD, CITY_DRIVE or COMBAT.
  3. Click INSTALL PROFILER. G-REDscript Profiler installs its native DLL under red4ext\plugins and creates its managed data/results folder.
  4. Do not begin the benchmark until the page reports PROFILER IS READY!.
3

READY — START THE TEST ENVIRONMENT

  1. If you are using a frame-time companion, start it first with START FRAME-TIME TOOL.
  2. Then launch Cyberpunk with START CYBERPUNK.
  3. For repeatable results, close unnecessary background applications before the capture.
  4. Load the save and reach the exact location/workload you want to measure.
  5. Press F11 once to START. G-REDscript Profiler gives one high beep.
  6. Run the workload, then press F11 again to STOP + EXPORT. The profiler gives two lower beeps.
  7. If Cyberpunk closes while a capture is active, shutdown is treated as an implicit STOP and the profiler attempts to export the useful capture collected so far.
4

CONFIRM A LIVE CAPTURE

After STOP + EXPORT, return to G-REDscript Profiler. The final v1.0.0 UI reports Live Captures: 1 when one completed game-side capture is ready for collection.

The number counts completed Capture_* folders, not ordinary text files such as CaptureTitle.txt.

The screenshot was taken immediately before the final wording cleanup and therefore says Live Files. The released build uses the clearer label Live Captures; the underlying count is unchanged.
5

COLLECT RESULTS / CLEAR LIVE

  1. Close Cyberpunk 2077 before collection.
  2. Click COLLECT RESULTS / CLEAR LIVE.
  3. The completed live capture is copied and verified into the portable profiler's RESULTS folder, normalized to the RED-YYYYMMDD-HHMMSS_TITLE archive layout, and then removed from the live game folder.
  4. The collected capture contains GRSP_Report.html and GRSP_Summary.json at the archive root, with detailed runtime/developer/metadata files under Data.
  5. If a recognized frame-time capture is available, G-REDscript Profiler also copies it into the result and adds correlation data. External frame-time source files are never moved or deleted.
In the final v1.0.0 build the status label shown here is Live Captures: 0 after successful collection.
6

RESTORE ORIGINAL STATE

  1. When you are finished profiling, make sure Cyberpunk 2077 is closed.
  2. Click RESTORE ORIGINAL STATE and confirm the restore.
  3. G-REDscript Profiler removes the manager-owned profiler DLL and managed data. Any remaining live profiler output is archived first when possible.
✓ RESTORE SUCCESSFUL — files returned to their original state.

Once the green confirmation appears, the profiling session is complete. Your collected results remain in the portable profiler's RESULTS folder.
