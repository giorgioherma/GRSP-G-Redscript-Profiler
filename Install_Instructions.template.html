G-REDscript Profiler

v1.0.0 — Installation, synchronized capture, collection and restore guide

KEYBIND → SETUP → INSTALL → CAPTURE → COLLECT → RESTORE

RED4ext — required

G-REDscript Profiler is a native RED4ext plugin. Cyberpunk 2077 and a working RED4ext installation are required before the profiler can be installed.

Frame-time profiler — recommended

G-REDscript Profiler works standalone, but pairing the REDscript capture with frame-time data lets the report compare script activity with actual rendered-frame behavior. This build was designed and tested alongside CapFrameX 1.9.1.2 Beta.

CapFrameX releases on GitHub
Capture key: G-REDscript Profiler currently uses a hardcoded F11 capture key for START and STOP + EXPORT. There is no GRSP keybind to configure. If you pair it with a frame-time tool, set that tool to F11 so both captures start and stop together.

0

MATCH THE FRAME-TIME CAPTURE KEY

G-REDscript Profiler itself is already fixed to F11. You only need to configure the optional frame-time tool to use the same key.

  1. Open CapFrameX and go to the CAPTURE tab.
  2. Under Capture settings, set Capture hotkey to F11.
  3. Leave Capture time [s] at 0 if you want F11 to control START and STOP manually.
  4. If you use another frame-time tool, configure its capture key to F11 instead.
No frame-time tool? Skip Step 0. GRSP works standalone and still uses F11 to start and stop the REDscript capture.
1

SETUP

  1. Extract the release ZIP to a normal writable folder and run G-REDscript-Profiler.exe.
  2. Click the first Browse... button and select the Cyberpunk 2077 game root. GRSP checks that the game and RED4ext are present.
  3. GRSP works standalone. For frame-time correlation, keep Run with a frame-time capture tool enabled.
  4. Select the frame-time profiler executable and its capture/results folder.
  5. Confirm the key information shows GRSP START: F11 and, when a companion is linked, that its capture key is also F11.
  6. Click CONTINUE →.
2

INSTALL THE PROFILER

  1. The status page should show Game: Found and RED4ext: Installed, with the REDscript profiler ready to deploy.
  2. Enter a useful Capture title, for example WORLD, CITY_DRIVE or COMBAT.
  3. Click INSTALL PROFILER. The manager installs the GRSP DLL under red4ext\plugins and creates its managed data/results folder.
  4. The title currently entered is saved during installation. Use SAVE TITLE later when you want to change the title for another capture.
  5. Do not begin the benchmark until the page reports PROFILER IS READY!.
3

READY — START THE TEST ENVIRONMENT

  1. If you are using a frame-time companion, start it first with START FRAME-TIME TOOL.
  2. Then launch Cyberpunk with START CYBERPUNK.
  3. For repeatable results, close unnecessary background applications before the capture.
  4. Load the save and reach the exact location/workload you want to measure.
  5. Press F11 once to START the REDscript capture and the synchronized frame-time capture.
  6. Run the workload, then press F11 again to STOP + EXPORT.
  7. If Cyberpunk closes while a GRSP capture is active, shutdown acts as an implicit STOP and GRSP attempts to export the useful work captured so far.
Consistency matters: for before/after comparisons, use the same route, scene, duration, graphics settings, game state and capture procedure wherever possible.
4

CONFIRM THE CAPTURE IS READY TO COLLECT

After STOP + EXPORT, return to G-REDscript Profiler. A completed game-side capture should now be listed in the live counter and COLLECT RESULTS / CLEAR LIVE becomes available.

The counter represents completed Capture_* folders, not ordinary metadata such as CaptureTitle.txt.

The supplied screenshot says Live Files. In the current v1.0.0 source this wording is Live Captures; the count itself is unchanged.
5

COLLECT RESULTS / CLEAR LIVE

  1. Close Cyberpunk 2077 before collecting.
  2. Click COLLECT RESULTS / CLEAR LIVE.
  3. GRSP copies and verifies the completed live capture into the portable profiler's RESULTS folder, normalizes it to the RED-YYYYMMDD-HHMMSS_TITLE archive layout, and then removes the verified live copy from the game folder.
  4. The collected archive exposes GRSP_Report.html and GRSP_Summary.json at the root. Detailed runtime, developer and metadata files are kept under Data.
  5. If a recognized frame-time capture is available, GRSP copies it into the result and rebuilds the report with frame-time correlation. External frame-time originals are never moved or deleted.
  6. The generated report opens automatically after collection. You can also use Open Results Folder at any time.
6

RESTORE ORIGINAL STATE

  1. When you are finished profiling, make sure Cyberpunk 2077 is closed.
  2. Click RESTORE ORIGINAL STATE and confirm the restore.
  3. GRSP first attempts to archive any remaining live profiler output, then removes the manager-owned profiler DLL and managed data.
  4. Wait for the green confirmation shown in the screenshot.
✓ RESTORE SUCCESSFUL — files returned to their original state.

Once this confirmation appears, the profiling session is complete. Your collected results remain in the portable profiler's RESULTS folder.

Do not leave the profiler installed for normal gameplay. Treat RESTORE ORIGINAL STATE as the final step of every finished profiling session.
